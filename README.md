# SFT / RL 运营分析台

这是项目现有的交互式运营看板，承接根目录 `docs/` 的业务口径和
`outputs/` 中的 Excel 原型。它不是正式主台账：默认数据均为虚构数据，
导入的 CSV 只在当前浏览器内存中解析，不上传、不持久化。

## 当前页面

- 运营总览：库存、发放、回收、完成、质检与异常提醒
- 回收分析：回收成熟度、未完成原因和待跟进任务
- 质检分析：双标一致、双标不一致、未双标三个抽检池
- 人员负载：标注与质检的分配、完成和近 5 个工作日负载
- 库存预测：SFT / RL 分线库存、消耗情景和原始批次
- 规则版本：版本分界、可比性和历史保护

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

校验命令：

```bash
npm run lint
npm test
npm run build
```

## 数据边界

- SFT 与 RL 的库存、批次、质量和版本始终分开计算。
- 首次发放的唯一数据量才扣减库存；双标、重发、返工不重复扣减。
- 跨规则版本的人效和质量指标默认不可直接比较。
- 接入公司真实数据前，必须完成公司信息安全审批。

部署项目由 `.openai/hosting.json` 中的 Sites `project_id` 继续复用。
